# RISC与CISC

## 定义
两种处理器指令集架构：RISC（精简指令集）强调指令简单高效，CISC（复杂指令集）提供丰富的单条指令功能。

## 核心解释
指令集是处理器能理解和执行的基本命令集合，是硬件和软件之间的接口。CISC（Complex Instruction Set Computing）以x86为代表，设计思路是一条指令完成更多工作，指令种类多而复杂。RISC（Reduced Instruction Set Computing）以ARM为代表，设计思路是保持指令简单统一，通过组合简单指令完成复杂任务。

历史证明RISC的设计理念更具生命力。简单的指令更容易被流水线高效执行，更适合现代处理器的超标量和乱序执行技术。ARM架构凭借RISC的低功耗优势统治了移动设备市场，而苹果M系列芯片的成功进一步证明了RISC在桌面和服务器领域的潜力。RISC与CISC的竞争是计算机体系结构发展中最精彩的篇章之一。
