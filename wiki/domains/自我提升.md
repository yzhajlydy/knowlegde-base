# 自我提升

> 认识自己、管理自己、持续成长的方法论集合。

## 核心概念

- [[如何养成一个好习惯]] — 选定一个新身份，用点点滴滴的小成就来向自己证明你就是这样的人
- [[GTD]] — 把所有要做的事情从大脑中清空，放到外部系统中管理
- [[精要主义]] — 更少但更好，只做真正重要的事
- [[时间管理]] — 通过规划、优先级排序和效率工具，有意识地分配和利用时间资源以实现目标
- [[健康管理]] — 通过合理的饮食、运动、睡眠和心理调节来维护和促进身心健康
- [[才能四象限]] — 以"特有/普遍"和"恒定/发展"为两个维度，将人的才能划分为四个象限的分析框架
- [[热量单位]] — 衡量食物能量含量的基本换算标准：脂肪约9千卡/克，碳水化合物约4千卡/克，蛋白质约4千卡/克

- [[1万小时定律]] — 在任何领域达到世界级水平需要约1万小时的练习，但长时间训练是必要条件而非充分条件，方法比时间更重要。
- [[3F方法]] — 通过专注（Focus）、反馈（Feedback）、修正（Fix it）三个步骤循环改进的学习方法。
- [[SMART原则]] — 设定目标时应遵循的五个要素：具体（Specific）、可衡量（Measurable）、可实现（Achievable）、相关（Relevant）、有时限（T...
- [[人生五种财富]] — 人生的财富包含五个维度：时间财富、身体财富、精神财富、社交财富和财务财富。
- [[伪工作]] — 把时间花在可有可无的事情上，看似忙碌实则没有产出真正价值的工作状态。
- [[四维度精力模型]] — 人的精力由体力、情感、思维和意志四个维度构成，高效能需要在四个维度上都保持充沛状态。
- [[图层工作法]] — 将工作按照相同属性分类，集中完成同一类任务以提高效率的工作方法。
- [[忧虑三步法]] — 面对忧虑时的三个步骤：找出最坏结果、接受最坏结果、全力改善最坏结果。
- [[情绪与行为互调]] — 通过调整行为来间接调节情绪状态的方法，因为直接控制情绪往往困难而控制行为更加可行。
- [[成功是成功之母]] — 先做成几件小事，学会成功的方法论和体验成功的感受，再逐步做更大的事。
- [[拖延公式]] — 行动力 = 期望 x 价值 / (冲动 x 延期)，揭示了影响一个人是否采取行动的四个关键因素。
- [[效率]] — 以最小的资源投入获得最大产出的能力，涉及工作方法优化、注意力管理和流程改进。
- [[格局]] — 一个人看待事物和处理问题时所展现的视野宽度和认知高度，做决策时格局要大。
- [[熵（反熵）]] — 心灵成长的方向与宇宙熵增的方向相反，需要持续不断地投入努力来对抗走向混乱的自然趋势。
- [[精力投资]] — 预见变化趋势，在关键节点高效投入精力的策略，如同投资一样追求精力的最优回报。
- [[能力三核]] — 知识、技能、才干三者构成的递进式能力结构模型。
- [[自律]] — 主动要求自己以积极的态度去承受痛苦，解决问题。
- [[赞同补充对比]] — 在意见分歧时使用的三步回应技巧：先找到双方一致的地方表示赞同，再补充自己同意但对方可能遗漏的内容，最后用对比法提出不同意见。
- [[通识教育]] — 在专业领域之外广泛掌握各学科基本知识和思维方式的教育理念。
- [[高考志愿选择]] — 城市＞学校＞专业。理由：城市提供机会，学校教你通识教育，打开眼界。
