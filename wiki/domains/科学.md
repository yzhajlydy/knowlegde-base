# 科学

> 科学不是知识的集合，而是认识世界的方法。

## 核心概念
- [[进化论]] — 进化论的核心思想是基因随机突变，环境自然选择
- [[人为什么会变老]] — 人之所以变老，是因为身上的某些细胞不再更新了
- [[睡眠]] — REM 睡眠，就是成长的关键期
- [[大脑发育]] — 什么是青春？从脑科学角度来说，只有额叶皮质还没成熟的那个人生阶段
- [[科学发现的必然性]] — 当知识积累和技术条件成熟时，同一时代多位研究者可能独立做出相同的科学发现

- [[CPT对称]] — 电荷共轭（C）、宇称（P）和时间反演（T）三种对称操作的联合对称，是粒子物理中最基本的对称性。
- [[不确定性原理]] — 海森堡提出的量子力学基本原理：无法同时精确测量一个粒子的位置和动量（速度），对其中一个量测量越精确，另一个量的不确定性就越大。
- [[事件视界]] — 黑洞的边界，是光都无法逃逸的分界面，一旦越过此边界，任何信息和物质都无法传回外部世界。

- [[四维时空]] — 将三维空间与一维时间统一为四维时空连续体的物理概念，时间是第四个维度。
- [[国际单位制]] — 用自然界的不变量来替代实验测量定义基本单位，确保全球计量标准统一且永不变动的度量衡体系。
- [[基因工程]] — 利用分子生物学技术对生物体的基因进行精确编辑和改造的技术，其中CRISPR-Cas9是目前最先进的基因编辑工具。
- [[复制因子]] — 能够复制自身、复制速度快且准确度高的稳定实体，是生命起源和进化的基础。
- [[大灭绝]] — 地球在约5.5亿年间经历了五次大规模生物灭绝事件，每次都有超过75%的物种消失。
- [[大爆炸理论]] — 宇宙起源于一个极度高温高密度的奇点，从那次"爆炸"开始膨胀并演化为今天宇宙的理论。

- [[希格斯粒子]] — 希格斯场的量子激发，是赋予基本粒子质量的"上帝粒子"，2012年在大型强子对撞机中被实验确认。
- [[广义相对论]] — 爱因斯坦提出的引力理论：引力不是一种力，而是物质导致时空弯曲的几何效应。
- [[弦理论]] — 一种统一量子力学和广义相对论的理论框架，其基本对象是一维的"弦"而非零维的点粒子。
- [[无穷数]] — 康托尔提出的比较不同无穷集合大小的方法，揭示了无穷也有不同等级。
- [[时间箭头]] — 时间有明确的方向性，至少存在三种箭头（热力学箭头、心理学箭头、宇宙学箭头）且它们方向一致。

- [[最大熵原理]] — 在满足已知约束条件的前提下，对未知部分不做任何额外假设，选择熵最大的概率分布。
- [[本福特定律]] — 在许多自然产生的数据集中，首位数字的概率分布并不均匀，数字1出现的概率最高（约30%），逐递减至9（约4.6%）。
- [[核裂变]] — 重原子核分裂为较轻原子核并释放巨大能量的核反应过程，铀235是自然界中唯一可裂变的天然物质。
- [[正态分布]] — 描述独立随机变量的和或均值所呈现的钟形分布规律，是统计学中最重要的概率分布。
- [[正曲率宇宙]] — 曲率为正的宇宙模型，其空间是有限但无界的封闭空间，类似于三维球面。

- [[测地线]] — 弯曲空间中两点之间的最短路径，是广义相对论中物体在引力场中的运动轨迹。
- [[涌现]] — 量变引起质变的现象，低层次组件的简单交互产生出高层次无法预测的复杂行为和性质。
- [[熵增定律]] — 在一个封闭系统中，熵（无序程度）总是趋向增大，系统从有序状态自发趋向无序状态。
- [[牛顿运动定律]] — 由牛顿提出的三大定律，描述宏观物体在力的作用下的运动规律，是经典力学的基石。
- [[物理学]] — 研究物质、能量及其相互作用的基本规律的自然科学，从亚原子粒子到宇宙尺度的现象都在其研究范围内。
- [[电磁统一]] — 麦克斯韦通过理论推导将电力和磁力统一为同一种基本力——电磁力，揭示了看似不同的两种现象本质上的统一性。
- [[科学方法论]] — 以质疑、求证、分解和普遍化为核心步骤的系统化认识和探索世界的方法。
- [[科学革命]] — 科学发展的本质不是线性累积，而是不断推翻旧知识、建立新知识的反常识过程。
- [[类群选择]] — 一种已被证明过时的进化理论，认为利他行为是在群体层面被自然选择保留下来的。
- [[粒子物理]] — 研究物质最基本组成单元（夸克、轻子、规范玻色子等）及其相互作用的高能物理分支。
- [[觅母(Meme)]] — 道金斯提出的概念，指文化传播的基本单位，类似于基因在生物进化中的角色。
- [[费米悖论]] — 宇宙如此广袤古老，理应存在大量外星文明，但人类至今未发现任何外星文明存在的证据，这一矛盾即为费米悖论。
- [[超导体]] — 某些材料在温度降至临界温度以下时，电阻完全消失，同时表现出完全抗磁性（迈斯纳效应）的物理现象。
- [[超生命]] — 一种广义的生命概念，包括传统生物和人工系统在内的所有具有生命特征的存在形式。
- [[进化生物学]] — 研究生物物种如何随时间演化、适应环境并产生多样性的生物学分支，核心理论是达尔文的自然选择。
- [[进化稳定策略]] — 由约翰·梅纳德·史密斯提出的概念：做大多数个体所做的事是一种进化上的稳定策略，突变者无法入侵。
- [[量子力学]] — 描述微观世界运行规律的物理学理论，其核心观点是世界不是因果决定的，而是由概率和可能性支配的。
- [[麦克斯韦方程组]] — 由四个偏微分方程组成的方程组，完整描述了电场和磁场的产生与相互关系，并预言了电磁波的存在。

- [[规模法则]] — 城市的经济产出、创新能力和基础设施随人口规模呈超线性或亚线性缩放的数学规律。
- [[哥德尔不完备定理]] — 任何足够复杂的自洽形式系统都包含无法在系统内被证明的真命题。
- [[元素周期表]] — 按照原子序数排列化学元素的表格，揭示了元素性质的周期性变化规律。
- [[波利亚过程]] — 一种正反馈的路径依赖模型，初始的随机事件会通过不断自我强化而影响最终结果。

- [[友谊悖论]] — 在社交网络中，你的朋友平均比你拥有更多的朋友，是网络科学的经典发现。
