# 【DONE】《娱乐至死》Neil Postman

因为科学技术带有某种偏向性，所以印刷术代表逻辑、论证、严肃，而电视则更多倾向于传播、娱乐，也并不是所有东西都适合用电视来呈现（政治、商业、宗教、教育、科学等），我们需要时刻警惕电视可能带来的信息轰炸

媒介即隐喻

媒介的形式在一定程度是会影响文化的，比如印刷术、电视传媒、互联网等

1. 在电视上，话语是通过视觉形象进行的，也就是说，电视上会话的表现形式是形象而不是语言
2. 媒介的形式在很大程度上能够控制文化（例如口头传播文化、字母记录文化、印刷术文化、电视文化、互联网信息文化）
3. 犹太人的上帝存在于文字中（《圣经》），这需要人们进行最精妙的抽象思考
4. 和语言一样，每一种媒介都需要为思考、表达思想和抒发感情感的方式提供新的定位，从而创造出独特的话语符号
5. 书面文字使思想能够方便地接受他人持续而严格的审查
6. 语言即媒介，媒介即隐喻，隐喻创造了我们文化的内容

媒介即认知论

文字比口头更要严肃、严谨

1. 任何一种媒介都有共鸣，因为共鸣就是扩大的隐喻。媒介有能力越过语境延伸到新的未知的语境中
2. 人们说的话比他们写下来的话要随意，书面文字是作者深思熟虑、反复修改的结果
3. 数字是发现和表述经济学真理的最好方式
4. 因为对真理的认知和表达方式是紧密相连的，所以一种从口头相传的文化，转向书面文字的文化，再从印刷术转向电视，其对真理的看法也在不断被改变
5. 在一个纯粹口语的社会里，非常看重人的记忆能力
6. 在一个印刷术的社会，非常看重语言前后逻辑关系

印刷机统治下的美国

1. 表达思想的方式会影响要表达思想的内容
2. 在18世纪，美国社会盛行阅读，几乎每个人都在阅读。当时大家对图书的吸引程度如同现今大家对美国橄榄球超级杯赛的关注度

印刷机统治下的思想

1. 1858年林肯-道格拉斯的辩论举世瞩目，当时的听众具有超常的注意广度，能够容忍7个小时的演讲；并且具备理解复杂长句的能力
2. 电视文化中的人们需要一种对于视觉和听觉都没有过高要求的“平白语言”
3. 建立在印刷文字上的口头语言，具有一种有语义、可释义、有逻辑命题的内容；推崇客观和理性思维，鼓励严肃、有序和具有逻辑性的公众话语
4. 在印刷时代，我们通过文字了解公众人物（例如美国的前15位总统，例如马丁路德金的著名演讲）；而在电视时代，我们通过图像来了解公众人物（比如尼克松、爱因斯坦），更多是想起他们的照片，而非他们的著作和文字
5. 在印刷机时代（或者叫“阐释时代”），美国人用白纸黑字来表明态度、表达思想、制定法律、销售商品、创造文学和宣扬宗教

躲躲猫的世界

电报的发明虽然加速了信息传播的速度，但与此同时也产生了非常多的垃圾信息

1. 在电报被发明后，报纸的财富不再取决于新闻的质量和用途，而是取决于新闻来源地的遥远程度和获取的速度。也就是说，电报的发明加速了信息爆炸
2. “信息—行动比”是一个能够有效衡量信息有效度的指标。而电报的发明大大提高了这个比例，产生了非常多的无用信息
3. 电报的主要力量来自于它传播信息的能力，所以它只适合于传播转瞬即逝的消息，因为会有更多更新的信息取代他们
4. 构成摄影的图像语言是具体的，与字词和句子不同的是，摄影无法观点、概念和抽象的东西，只能具象化（照片只能辨认，文字却需要理解）
5. 电视则为电报和摄影提供了最有利的表现形式，把图像和转瞬即逝的信息发挥到了完美境界，进入到了千家万户

娱乐业时代

问题不在电视的娱乐属性，而在于他把所有的内容都以娱乐的方式表达（宗教、教育、政治、经济等）

1. 每种技术都有自己内在的偏向（如印刷术偏向思维逻辑、电报偏向信息传播、电视偏向图像和信息的综合、互联网则是大综合）
2. 我们的问题不在于电视为我们展示具有娱乐性的内容，而在于所有的内容都以娱乐的方式表现出来
3. 电视本身的性质（图片，画面为主），决定了必须舍弃思想，来迎合人们对视觉快感的需求，适应娱乐业的发展

“好...现在”

1. 新闻是零散不全的（不连贯性），而且没有背景、没有结果、没有价值、没有任何严肃性的新闻，即新闻成为了娱乐
2. 电视为重新定义了什么是真实性：讲述者的可信度决定了事件的真实性

走向伯利恒

1. 在电视上，宗教和其他东西一样，被表现为一种娱乐形式。背后的原因出在电视的本身形式，而非传教士自身缺陷
2. 不是一切都是可以用电视来表达的。电视把某种事物转换成了另一种东西，原来的本质可能丢失
3. 观众需要在一种非世俗世界的神秘氛围中才能获得超凡脱俗的宗教体验，显然电视无法提供这样的机会

伸出你的手投上一票

1. 电视广告是塑造现代政治观点表达方式的重要工具
2. 广告讲究的是短小简单、表演优于说理，得到解决方法由于面对问题
3. 广告通过给一个口号、象征或给观众创造出引人注目的形象焦点来获得注意力
4. 奥威尔认为政府会通过赤裸裸的压制来控制信息流动，特别是禁书的方式

教学是一种娱乐活动

1. 电视节目并没有鼓励孩子热爱学校，而是鼓励孩子热爱电视
2. 一个人学到的最重要的东西就是学习的方法，而非学习内容
3. 电视对教育的主要贡献是提出了教学和娱乐不可分的理念。认为：孩子在学习有兴趣的东西时掌握得最好
4. 电视教学的三个弊端：
5. 没有前提条件和背景知识直接学习，不系统
6. 因为不能让观众有困惑，否则降低收视率，所以学习过程没有难度
7. 没有阐述过程，争论，讨论，说理都没有
8. 教学内容的选择更多受制于电视节目，而非孩子真的需要学这方面知识（例如鲸鱼和它们的生活环境）

赫胥黎的警告

1. 为我们提供纯粹的娱乐是电视最大的好处，最糟糕的用处是企图涉及严肃话题：新闻、政治、科学、教育、商业和宗教
2. 并不是抵制电视，而是重新定义和改变我们对新闻、政治辩论和宗教思想等看法，而非停止看电视
