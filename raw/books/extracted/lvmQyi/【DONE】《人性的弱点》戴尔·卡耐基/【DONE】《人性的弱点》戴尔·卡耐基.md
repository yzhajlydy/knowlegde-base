# 【DONE】《人性的弱点》戴尔·卡耐基

人性最大的弱点就是每个人都希望别人重视，找到他的需求是什么，满足他即可达到你任何想达到的目的。

人际关系基本技巧

1. 绝大多数情况下，不管犯下多严重的错误，人们都不会责备自己
2. 当人们被批评时，下意识会为自己辩护，以同样的指责回击
3. 批评、指责和抱怨是人与生俱来的本能，理解和宽容却是对人品和自律的极大考验。不要批评，不要指责，不要抱怨
4. 人性中最深层次的动力是“对重视”的渴求，强烈渴求着他人的欣赏
5. 我们总是对伴侣的付出习以为常，却忘记了他们也需要被称赞、被感激。父母对孩子的重视、称赞也是一样
6. 正常人永远都只在乎自己的欲望，然而其他人对你的欲求毫无兴趣，他们和你一样，只在意自己想要什么。所以普天下唯一能够影响他人的方式，就是找出他们想要什么，并且教给他们如何获得

赢得他人喜爱的六个方式

1. 发自内心的关注他人，欣赏对方。比如记住对方的生日，姓名，聊对方感兴趣的话题等
2. 脸上的神情比身上的衣着重要的多。时常微笑
3. 每个人都希望自己的名字永垂不朽，为此付出任何代价都在所不惜。请牢牢记住记住对方的名字
4. 变得健谈的方法：多倾听对方，专注的倾听，鼓励对方多说话。包括眼神注视，全神贯注等
5. 你的谈话对象并不关心你和你的问题，他只对自己和欲望和烦恼感兴趣，谈论对方最在乎、感兴趣的事情

如何让他人想你所想

1. 一个人发火的时候，另一个人必须听着。如果两个人都在大叫大嚷，那不叫沟通，叫噪音
2. 与对方沟通时，把握求同存异的原则，接受分歧，目标达成一致
3. 尊重他人的观点，绝不要说“你错了”，切忌当面指出别人的错误
4. 如果自己错了，在对方开口之前抢得先机，自己检讨，果断承认错误
5. 与人商谈时，请先强调你赞同的观点，不要急于挑明分歧。让对方了解，你们的差异在于方法而非目的
6. 站在对方的角度看待问题，并争取让对方说“是”
7. 循循善诱，让对方自己得出结论，而不是我们强加给对方的想法
8. 设身处地的从对方角度思考问题：”如果我是他，我会怎么想，又会怎么做“

成为领导者，如何改变他人

1. 在说出令人不快的事情之前先给对方一些肯定，更容易让对方接受。欲抑先扬
2. 以称赞开始，以“但是”转折，以批评收尾。可以将“但是”更换为“而且”，更能令人接受
3. 赞美替代批评。且赞美要尽可能具体，细节，有理有据，而不是假意逢迎
4. 如果你希望对方提高某方面的能力，就先假装他早已拥有这一品质，做正向激励

幸福家庭生活的七个法则

1. 停止唠叨
2. 不要试图改变对方
3. 学会欣赏对方，多赞美对方
4. 女人极为看重生日和纪念日，不要问为什么，没有为什么
5. 回家之前把工作中的烦恼留在门外
6. 尽管男人认为一个心满意足的妻子和一个快乐安宁的家庭远胜于百万美元，但是99%的男人都不会严肃考量这个问题，也不会把婚姻当做事业一样认真经营。他在人生中最重要的这件事情上听天由命，婚姻的成败全凭运气
