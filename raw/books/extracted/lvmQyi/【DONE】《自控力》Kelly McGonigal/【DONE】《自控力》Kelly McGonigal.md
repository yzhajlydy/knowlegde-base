# 【DONE】《自控力》Kelly McGonigal

1. 冥想其实是不断强化自己意识的过程，从杂乱无章的思绪中不断集中精力到呼吸上。这种状态其实和抵抗诱惑的过程很相似，也就是意识到自己正在失控，需要集中精力来控制自己。
2. 自控力和血糖有关，血糖越低，自控力越低;反之，自控力会增强。所以当你感觉自控力不足时，尝试吃一颗糖
3. 可以尝试一种
4. 压力放松方法1：躺下来，枕头垫着膝盖，腿稍稍抬起，闭眼，深呼吸，全身放松。
5. 压力放松方法2：锻炼身体、祈祷、阅读、听音乐、和朋友家人在一起、按摩、散步、冥想、瑜伽
6. 10分钟法则：控制不住自己的行为时，用10分钟法则。10分钟内不要做这件事，10分钟后如果还想做，再去做。原理是借助“延迟奖励”，即大脑对未来的奖励是会打折扣的。
7. 自控力会传染：经常和自控力强的人在一起，你的自控力也会逐步提高；反之亦然。
