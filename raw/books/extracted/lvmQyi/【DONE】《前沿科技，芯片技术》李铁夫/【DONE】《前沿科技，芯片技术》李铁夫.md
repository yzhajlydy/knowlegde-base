# 【DONE】《前沿科技，芯片技术》李铁夫

1. 芯片的本质是半导体（Si）+集成电路（把电路直接做在硅片上）
2. 在半导体之前，人类只能用机械控制电。但是有了半导体之后，人类才可以直接用电来控制电。在栅级施加电压，实现电路的通断。
3. 基于半导体芯片的理论极限是一个硅原子的直径：0.2纳米
4. 0.2nm之前还有一个热力学限制（1nm左右）；量子力学限制（状态干涉）
5. Intel i7处理器，它的功率密度大概是50 W/cm²；专业芯片功率密度最高甚至达到了380 W/cm²；火箭喷嘴那里也不过是600 W/cm²
6. 芯片制作的3+2过程
7. 设计【EDA软件】、加工（台积电）、测试
8. 制造设备【光刻机：荷兰ASML，极紫外光刻机光源直径13.5nm，250W光源功率，效率比上一代EUV光源更高；葵司镜片】、高纯度材料
9. 芯片产业不是全球化市场而是会员制俱乐部
10. 世界三大EDA公司中的两家Cadence和Synopsys都是美国公司；第三家被德国收购，但是总部依然在美国
11. ARM追求功耗，采用RISC精简指令集（移动端设备）；Intel追求性能，采用CISC复杂指令集（PC）
12. ARM还采用了授权的商业模式
13. 方式1：提供完整的或者模块化的处理器设计方案
14. 方式2：购买架构和指令集方案，自行设计芯片（苹果、华为）
15. 摩尔定律能走到今天的最大功臣是登纳德等比例缩小方案，通过不断把器件做小，缩小晶体管沟道尺寸来提高芯片性能
16. 前沿技术：环绕栅晶体管（GAAFET）
17. 减小漏电
18. 前沿技术：片上系统SOC
19. 集成了CPU、GPU、存储器、图形处理器、音频视频模块
20. SiP比SOC难度低，只是封装层的改进
21. 前沿技术：碳纳米管或者石墨烯这类低维材料，它们最大的优势是电子在其中的传输速度比在硅材料当中要快得多
22. 前沿技术：电子自旋方向代表0，1
