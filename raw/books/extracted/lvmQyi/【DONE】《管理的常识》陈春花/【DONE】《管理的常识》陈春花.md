# 前言&序

**管理是为了解决问题，包括“人”的问题、“事”的问题**。管理的关键在于问题的挖掘是否到位，通过结合人与事，使产出最大化。管理三步骤：劳动效率、组织效率、个人效率，且不能跳跃

1. 管理所面临的主要问题是:处理“人”和“事”
2. 管理不能用成就做导向,只能用问题做导向。解决一个问题迎接下一个问题
3. **管理的关键:在于问题的挖掘是否准确到位**[^1]
4. 管理的定义: 为了实现目标,人与机构内资源一起工作; 让你的上司和下属获得绩效5.管理的检验:结果检验和外部评价,不由自己评价
5. 管理的核心价值:是激活人,让人与事,人与资源组合的时候,产出最大化
6. 第一重价值:发挥员工价值
7. 第二重价值:激发员工价值
8. 第三重价值:激发团队潜力
9. 管理是一种实践,其本质不在于知,而在于行
10. **管理的目的:是提升效率**（劳动效率→组织效率→个人效率）[^2]
11. 管理的演变历史:劳动效率,组织效率,个人效率。三个效率为递进关系,金字塔结构。要提升个人效率,必须提高组织效率,要提高组织效率,必须提高劳动效率
12. 管理的两个属性:实践与经验属性; 知识(理论)属性。只要拥有其中一种都可以把管理做好
13. **管理没有对错,只有面对事实,解决问题**[^3]

# 什么是管理

管理围绕绩效第一展开讨论，其岗位设计必须满足责任、权利、利益共同分配原则，分三个阶段：劳动效率（分工明确）、组织效率（专业化+等级制度）、个人效率（挖掘需求）

企业管理的五个方面：计划管理（资源与目标）、流程管理（人员与岗位）、组织管理（权利与岗位）、战略管理（核心竞争力）、文化管理

1. 管理的理解:
   1. 管理就是让下属明白什么是最重要的(引领方向)
   2. 管理不谈对错,只是面对事实,解决问题(没有绝对的对与错,在不同场景下,对错是可以互换的; 所有的管理行为都是为了解决问题的)
2. 管理是“管事”而不是“管人”
3. 衡量管理水平的唯一标准是能否让个人目标与组织目标合二为一
4. 管理就是让一线员工得到并可以使用资源(人力、财力资源)
5. 组织管理观:
   1. 管理只对绩效负责。绩效第一,其他第二[^4]。比如功劳与苦劳,能力与态度,才干与品德谁重要的问题。 关于才干与品德,两种情况下看才干: 招聘+提拔人员
6. 管理是一种分配。 责任、权利、利益的分配。 这三者的关系必须是等边三角形。缺一不可
7. 管理始终为经营服务。 经营(目标)能力是选择正确的事做, 管理能力是把事做正确。 显然经营第一,管理第二。 不同的目标,有不同的管理方法
8. 管理解决的三个效率(三种效率是逐步递进过程,不可颠倒顺序)
9. 使劳动生产率最大化的手段是分工。泰勒在《科学管理原理》中提出的劳动生产率最大化的四条原理:第一条为科学划分工作元素
10. 使组织效率最大化的手段是专业化水平和等级制度的结合
11. 组织管理的核心是让权力回归到职位上,也就是组织本身,而不要停留在个人身上
12. 权力需要承担职责,没有职责的权力是不存在的
13. 使个人效率最大化的手段是个人创造组织环境,满足需求,挖掘潜力
14. 将组织目标和个人目标合二为一的激励才是有效激励
15. 如何让管理有效
16. 传统管理者的特征:
    1. 只关心发生的事务,自己的时间属于别人
    2. 屁股决定脑袋,缺少全局观
    3. 只关注事务,忽略对人的培养
17. 有效管理者的特征:
    1. 时间管理。确定重要的事情并正确排序
    2. 系统思考。认识到整体和局部的关系
    3. 培养人。发挥下属和上司的绩效
18. 计划管理、流程管理、组织管理、战略管理、文化管理。五项管理内容是递增关系。其中,前三者为企业管理的基础管理,是生存关键。
    1. 计划管理(回答资源与目标是否匹配的问题)
       1. 目标管理实现的三个条件: 高层强有力的支持; 目标能够被检验; 目标清晰[^5]
       2. 计划管理实际上是管理资源,不是管理目标
    2. 流程管理(解决人与事是否匹配的问题)
       1. 流程优于组织。关注流程目标、时间,以客户需求为导向
    3. 组织管理(回答权力与责任是否匹配的问题)
    4. 战略管理(解决企业核心能力的问题)
       1. 核心竞争力首先应当是深入理解和准确把握市场和顾客需求的能力
    5. 文化管理(解决企业持续经营的问题)

# 什么是组织

组织的存在是为了实现某个目标，且能够兼顾稳定性和变化性。在设计时需要符合一定原则，包括：一个上司、小管理幅度、分工明确、部门化

1. 组织的存在是为了实现目标,组织管理的存在是为了提升效率[^6]
2. 公司不是一个家
3. 组织本身的属性是权力、责任和目标。以绩效产出为导向,不是讲情感的地方。当然,如果既有效率,又有情感,那是一家非常好的公司
4. 组织必须保证一件事由同一组人承担(权责分工明确),谨防“组织虚设”(有权利无责任)
5. 在组织中人人公平而非平等
6. 分工是个人和组织联结的根本方法
7. 组织分工指的是权力和责任的分工
8. 组织内的关系是奉献关系,不是管理与被管理的关系,甚至也不是“合作”关系
9. 组织结构一方面要保持稳定,因为只有稳定的结构才能产生效率; 另一方面又要能够随时变化,因为只有变化的结构才会适应新环境,带来发展
10. 组织结构的功效
    1. 组织结构索要解决的是权力与责任关系是否匹配的问题
    2. 组织结构需要设计:沟通线、控制线、责任线、权利线。其中权力和责任线是纵向的(权力指令),沟通和控制线是横向的(如何沟通,控制资源)[^7]
    3. 纵向的设计以考核点作为原则进行分层设计,有多少个考核点,就可以分多少层
    4. 横线设计以主业务对职能部门的需求来决定。 原则是尽可能少
11. 组织结构更需要依据责任而不是权力来设定
12. 组织结构设计服从于企业战略,而不是各自为政
13. 组织结构设计原则
    1. 第一原则:指挥统一。即一个人只能有一个上司[^8]
    2. 第二原则:控制幅度。 即管理跨度,下属人数,越往高层人数越少[^9]
    3. 第三原则:分工。纵向分工就是绩效、权利的体现。 横向分工是资源线,在这条线上进行专业分配,保证业务部门能够获得支持
    4. 第四原则:部门化。 把同一件事的人放在一个部门里交给一个经理负责,不要分散
14. 组织结构需要配合企业发展的需要
15. 影响组织结构调整的四个因素: 策略(战略目标)、规模(人数)、环境(社会环境)和技术(技术要求)
16. 创业阶段(直线型组织架构): 直线型组织架构。理由是集所有权、经营权合二为一,决策集中,效率最高,成本可控,有竞争优势
17. 成长阶段(职能型特点):职能型部门,追求部门专业化。 所有权和经营权还在创业者手里
18. 持续发展阶段(董事会制特点):文化价值认同和理念认同阶段,所有权和经营权再次合二为一
19. 常用组织结构优劣分析
    1. 职能型结构
       1. 同类专家组合在一起,减少人员重复。但是每个职能部门各自为政,无法配合,无全局利益
    2. 事业部制
       1. 事业部是自治单位, 专心致力于长远战略规划。 但是会出现资源重复配置问题
    3. 扁平化结构
       1. 反应快、灵活。风险较大,适用于小型企业
    4. 矩阵式结构
       1. 公司资源有限,但是又希望规模増长时使用

# 什么是领导

领导技能的三个方面：人际技能、概念技能、技术技能。其中高层领导者尤其需要概念性技能，能够理解复杂概念，且能够把复杂问题简单化[^10]

1. 领导的理解(影响力组成:权力+个人魅力)
2. 权力产生的影响力:法定权、专家权、奖赏权、惩罚权、统治权
   1. 法定权、专家权、奖赏权应该多使用, 而统治权和惩罚权尽量少用
   2. 魅力包括:外貌、类似性(保持目已和群众是一体的,不要永远尝试证明自己是正确的,其他人是错的)、好感回报(你对怎么别人,别人就怎么对你)、知识、能力(把问题交给合适的人解决,而不是自己全部解决)
3. 领导者与管理者的差异:
   1. 领导者:订立方向、构建团队,促进变革。有明确方向,及时适应变化
   2. 管理者: 解决问题、保持稳定、按章行事。 为绩效负责
4. 领导技能的三方面内容:
   1. 人际技能。核心能力(基层、中层、高层都需要)
   2. 概念性技能。 能够明白整个机构的复杂性(高层需要)
   3. 技术性技能。 基础技能、方法能力(基层需要)
5. 高层管理者最关键的能力是: 复杂问题简单化
6. 如何让授权有效
   1. 培养人的最佳办法的就是分配责任,授权给他,让他成长起来
7. 授权的关键是目标设定不授权,只授权资源。否则目标一旦放权后会出现不受控,导致任务无法完成

# 什么是激励

激励是让人们愿意付出，有激励因素和保健因素。其中，金钱是最重要的激励因素。有效激励的三个要素：重要性、公开性、公平感（付出多）

1. 激励就是让人们自己做出选择并愿意付出
2. 激励永远要站在对方的角度来做,不要站在自己的角度
3. 人为什么而工作?赚钱、消耗能量、社会交往、成就感、社会地位[^11]
4. 提供给人们的工作条件分为激励因素、保健因素。 称为双因素理论。 其中激励因素:晋升、奖金、价值肯定等;保健因素:工资、岗位、培训、福利条件等。因此,涨工资并不会带来满足感,原因是涨工资是保健因素,是工作应得的
5. 福利是保健因素,在福利设计和调整时,要非常谨慎,哪怕是几元钱的午餐补助,也不能随意取消[^12]
6. 马斯洛需求层次理论:生理、安全、交往、尊重和自我实现。 奥德夫将其合并,规整为生存、联系、成长。且任务需求并非逐级递进,而是多种需求同时存在; 当一种需求遇到挫折时,会降低需求,回归到更第一层次的需求上
7. 对那些有能力的核心人才,除了需要经常与他们讨论自我实现和尊重,更要关注他们的生活状态,给与更多的关心和照顾,让他们活的更加自由
8. 激励不发挥作用的情况
   1. 工作超量所造成的疲惫
   2. 角色不清,任务冲突
   3. 不公平的待遇
9. 不公平是绝对的,公平是相对的
10. 公平本身是一种感觉,是一个人的判断。公平理论的核心是比较一个人的付出,而非获得。我们往往对公平的判断是基于获得(即是否平均),而公平感的真正来源应该是获得与付出的比率
11. 金钱是最重要的激励措施。不要把“对金钱的看法”和“金钱在激励上是否重要”两者混淆。前者可以说金钱没那么重要,但是后者的答案十分明确:金钱非常重要
12. 衡量采用的激励措施是否有效的三个特征:
    1. 重要性(金钱在当今社会的重要性)
    2. 可见度
    3. 公平感(比较付出,而非获得)
13. 对于低层次的人来说,较少的金钱可以获得较高的激励效果; 而对高层次的人来讲,需要很多的钱才能达到相同的激励效果
14. 成本最低且最有效的激励措施
    1. 鼓掌(9次以上)
    2. 赞美(管理者的直接表扬)
    3. 鲜花
    4. 隆重的仪式(入职纪念杯)

# 决策如何有效

重大决策的核心是控制风险，控制风险的最好方式就是集体决策。个人决策风险虽高，但是效率也高

1. 集体决策,个人负责[^13]
2. 决策的目的是为了执行,而不只是单纯的做选择题
3. 从识别问题开始,做出决策的一组人和执行决策人的一组人必须是同一拨人。 否则就是流程、业务两张皮
4. 管理者必须具备自然科学和社会科学两种思维方式。 前者是数理化推理逻辑,从数据、实验中不断犯错,找到真理的方式; 而后者则是文学、史学、哲学的综合,不能犯错误,一次错就无法挽回,与自然科学的思维方式刚好相反。 因此,管理者在做决策时,需要综合考量诸多因素,包括数据、经验、其他环境条件和人因素等
5. 个人决策的局限性
   1. 首因效应(刻板印象)
   2. 晕轮效应(光晕蒙蔽)
   3. 新近效应(判断一个人仅仅看他最新的表现)
   4. 角色固着
6. 决策有效的评估标准
   1. 决策方案的品质(方案本身合理性)
   2. 成员的接受程度(影响成员的支持程度)
   3. 若品质高于接受,则可以用独断式决策;若接受高于品质,则可以用群体决策(共识);若两者都重要,则可以用咨询式决策(听取部分专家意见)
7. 重大决策的核心是控制风险,而控制风险的最好决策方式就是群体决策。初创公司可以使用独断式决策,寻求机会,快速发展;而大公司则需要尽可能降低风险,使用群体决策

# 什么是计划

如果计划没有变化快，只能说明计划时没有考虑到变化

1. 计划是为了实现目标而寻找资源的一系列行动,而不单单只是定个目标,分解目标,然后拍个时间表如此简单
2. 目标是不合理的。目标是对未来的预测。目标不是基于现在的资源设定出来的,而是基于未来的发展趋势和竞争给出来的目标。 因此,我们不要去质疑目标的合理性,因为他一定是不合理的。和上司不能对目标进行讨价还价,可以讨价还价的是资源[^14]
3. 制定计划的关键是搞清楚理想和现实的差距,不仅仅要做分解目标,讨论目标的可行性,还需要弄清楚我们在哪里,我们要往哪里去, 以及去过中途需要使用哪些资源
4. 计划没有变化快的原因是: 计划没有涵盖变化,是计划本身没有设计好。一个好的计划一定是可以包含变化,是可以预测趋势的
