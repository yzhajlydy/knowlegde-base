# 【DONE】《奇特的一生》格拉宁

1. 纯时间概念。每天在公司待14个小时，其实有效工作时间很短，排除吃饭，睡觉和扯淡的时间，真正用在工作上的纯时间也就3-6个小时。
2. 时间感知能力。通过时间统计法，培养对时间的精准感知，有助于安排个人时间规划。
3. 看一个人的价值就看他对时间的态度，一个说自己爱看书，爱工作的人，一天只花10分钟看书，2小时工作，那他是个那样的人吗。
4. 吃饭的几块钱和买车的几块钱都是一样的，吃饭的时候纠结那么几块钱，为什么买车的时候几万块就不纠结了呢？一块钱放哪儿都是一块钱，不要因为其他因素影响我们对金钱的判断。时间也一样。工作的一小时和放假的一小时一模一样，千方百计的在工作中抓紧那么一小时，其实在放假的时候那一小时的重要性和工作一样，不要浪费时间。
