# 【DONE】《如何阅读一本书》Mortimer J. Adler

阅读需要回答最重要的一个问题：这本书和你有什么关系？

快速阅读的技巧：书名、出版社介绍、序言、目录、索引、随便找一个段落阅读

主动阅读

分为两个方面：一是要求阅读主动，积极思考；二是要求有一定的阅读技巧。

阅读的目标

为了获得资讯而读（知道而已），为求得理解而读（理解）

带着四个问题阅读

1. “这本书在说什么？”
2. “作者细部说了什么，都是怎么说的？”
3. “这本书说的有道理吗？是全部有道理还是部分有道理？”
4. “这本书跟你有什么关系？”

阅读的四个层次

1. 基础阅读（字面理解、“这个句子在说什么？”）
2. 检视阅读（在规定时间内完成高质量的阅读、略读、粗读、“这本书在说什么？”）

略读了解全书基本架构

粗浅阅读了解全书大致内容

1. 先看书名页，再看序言部分。有译序和序言，重点看序言，里面可能有一些全文的架构梳理
2. 研究目录页，对这本书的基本架构做概括性的理解
3. 如果有索引，也要检阅一下。从而看出整本书的议题范围
4. 如果书被书衣包裹，可以阅读出版社的介绍。因为这一块文案一般都是由作者写的，可以高度概括书本的主旨
5. 从目录中挑出与主题息息相关的篇章，然后阅读他的开头或者结尾的摘要说明。
6. 最后一步，随便翻几页读一读，可以是一两段，也可以是一两页，留意主题的基本脉动。尤其注意书本的最后两三页内容
7. 分析阅读（在无限的时间里做最好的阅读、追求理解）

分析阅读的三个阶段：

1. 找出一本书在谈些什么

- 知道这本书的种类和主题
- 用最简短的文字说明整本书在说谈什么
- 列出全书的大纲，并将各个部分的大纲也列出来

1. 诊释一本书的内容

- 诊释作者的关键字，与他达成共识
- 从最重要的句子中，抓住作者的重要主旨
- 知道作者论述的是什么，找出相关句子
- 确定作者已经解决了哪些问题，还有哪些没有解决

1. 像是沟通只是一样地评论一本书

- 不要轻易批评一本书，除非你已经能够很好的诠释这本书的主旨
- 不要争强好胜，非辩到底不可
- 在评论之前，自己能够区别出真正的知识与个人观点的不同
- 证明作者的知识不足、知识错误、不合逻辑、分析理由不完整等

1. 主题阅读（阅读不同类的书籍）

主题阅读分两个阶段：

（1） 准备阶段

针对要研究的主题，设计一份实验性的书目

浏览书目上的所有书，确定哪些与你的主题相关，并就主题建立起清楚的概念

（2） 主题阅读阶段

浏览在准备阶段中认定与主题相关的书，找出相关的章节

根据主题创造出一套中立词汇，带引作者与你达成共识

建立一个中立主旨，列出一连串问题，理清问题

界定主要和次要议题

分析这些讨论

阅读速度

超快的速读法并不总是一项值得称赞的成就，那只能说明你在阅一种根本不值得读的读物

暂缓评论

在说出自己的意见之前，无论是“同意”或者是“不同意”，都一定要说一句话：“我了解了”。意思是在评论别人的想法之前，必须确保自己是完全理解对方的，否则只是在浪费时间。这也不是尊重别人的表现。

阅读能力提升常识

如果你所读的书在你的能力范围内，你就没法提升自己的阅读能力（工作也是如此）

阅读做笔记的方法

- 重点句下画横线或双横线
- 空白处星号（慎用，一般用于整本书的核心重点）
- 空白处标记页码，用于提示在其他章节出现的类似观点或者不同观点

三种笔记分类：

结构笔记：检视阅读笔记。用于体现全书的架构，不包括具体内容和细节。

概念笔记：分析阅读笔记。罗列作者的观点和自己的观点。

辩证笔记：主题阅读笔记。从不同的书中摘取很多观点，对比陈述并摘出矛盾。
