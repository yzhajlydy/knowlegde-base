# 房贷合同要变了，LPR利率和固定利率哪个合算，会影响房价走势吗?

1. 利率=基准利率 \*（1+浮动）；其中中央银行给出基准利率，而银行自己可以调整浮动利率

   ![](image/prwTP3W4prCLKWCcfbFEpX_gIICVJE6BV.png)
2. 利率双轨制。市场利率是央行通过MLF贷款给商行的一种利率，商行根据MLF自己选择向不向央行借钱；政策利率是商行贷款给个人/企业的利率，是央行决定的。存在政策利率受到政府干扰问题，为了避免政策干扰，用LPR利率取代固定基准利率

   ![](image/k133KmpxqcMcALipEBPjHR_P_l-ZDuj25.png)
3. LPR=MLF（央行决定）+加点（18家银行共同投票决定）
4. 商行给个人/企业的住房贷款利率=LPR+加点（根据企业和个人的信用情况）

# 天空为什么是蓝的？

1. 黑体辐射：只向外辐射，不吸收的物体；太阳就是一个黑体；黑体辐射能量在不同波段的曲线呈现一个钟罩型，这种特性使得我们人眼进化成了能够看见可见光

   ![](image/9RtRCVZykWGZntde63V2vE_YDGlCYEEa_.png)
2. 波长越长，散射能力越弱，波长越短，散射能力越强
3. 月亮上没有大气层，没有散射，所以天空都是黑的，不是蓝的
4. 日出、日落的时候，太阳光斜照着地面，经过了厚厚的大气层，蓝光被散射掉，只剩下红光
5. 颗粒物尺寸远远小于光波波长尺寸：符合瑞利金斯散射公式

1. 阻尼器作用原理是通过二级减震系统，将大质量块的运动动能转移给小质量块的运动动能，并以内能（油阻尼杆）或者电能（涡流阻尼器）的方式耗散掉
2. 设计思路：
