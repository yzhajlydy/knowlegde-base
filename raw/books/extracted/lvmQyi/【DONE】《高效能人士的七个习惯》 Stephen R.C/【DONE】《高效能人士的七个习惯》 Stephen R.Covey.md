# 【DONE】《高效能人士的七个习惯》 Stephen R.Covey

变化的世界，不变的原则。掌握原则（公平、诚实、尊重、远见、责任、主动性）的重要性。

七个习惯总体概述：（前三个属于个人领域的成功，后四个属于公众领域的成功）

1. 积极主动

   由自己的一套的“自我意识”、“想象力”、“良知（最为重要）”、“独立意识”对环境的刺激做出回应，这个回应的过程就是积极主动的模式。如果是积极主动人，不会被外界的环境所干扰，对待事物有自己的价值观。

   扩大影响圈，慢慢接近关注圈，然后再逐步扩大关注圈。从底层的工程师到高层的项目经理的过程，就是一个从影响圈到关注圈的例子。如果反过来把焦点全部放在关注圈，那么自己的关注圈就会越来越小，直到缩到自己的影响圈。做事的事情想着“我可以……”，而不是“如果……”
2. 以终为始

   任何事物都要经过两次创造。先思考，再实践。工作内容也是，先领导，再管理。领导≠管理（左脑管理，右脑领导），领导是方向，必须要正确；而管理则是注重方法。如果方向错误，那么方法再正确也无济于事。

   个人使命宣言vs.个人宪法（任何时候做的任何事情，是否符合你的个人宪法呢？）

   以原则为中心的生活状态。（安全感、人生方向、智慧、力量），保持冷静和客观，不受情绪和周围环境的影响，纵观全局考虑、经过深思熟虑后的决策结果。

   如果一个是他是积极主动的，那么他一定是知道自己想成为怎样的人。能够写出自己的使命宣言，甚至是个人宪法。
3. 要事第一

   四象限时间管理，把关注点放在第二象限上，也就是“重要不紧急”的事。并且避免进入第三和第四象限。
4. 双赢思维

   如果不是双赢，就好聚好散
5. 知彼解己

   移情聆听，感同身受。知彼解及的首要是要了解对方，知道对方在说什么，然后再去向对方解释自己的想法。这种方法完全可以应用在婚姻生活中。

   想要表达自己，必须做好三条：品德第一、感情第二、理性第三。意思是，自己的可信度是首要的，其次是你对他的理解能力，最后才是你的逻辑能力，也就是你的表达能力。由此可见，我们在平常的交流过程中，只在乎如何表达自己的观点（使用个人魅力），而完全忽略了更为重要的前两条原则。
6. 统合综效

   在团队中发挥每个人的能力，即1+1>2

   这种观点的基础就是尊重差异。当你看到你与别人的差异时，首先要想到的是“对方的主张必定有我尚未体会的奥妙，值得加以了解”，而不是“想方设法的纠正对方的‘错误’，说服对方”。
7. 不断更新

   四个层面的不断更新：身体（锻炼身体）、精神（个人宣言）、智力（学习知识、阅读）、社会/情感（移情沟通）。

从习惯一到习惯六的螺旋式上升阶段。

以原则为中心，以品德为基础，由内而外。不要尝试去用个人魅力解决事情，比如圆滑的处事方式，厚黑学等。我们逐渐培养基于原则的思维定式（非定势）。

原则不是价值观。比如一群盗匪可能有相同的价值观，但是他们却违背了善良的原则。也就是说，原则是真理，而价值观有正确和错误之分。

成熟的三个阶段：依赖（Dependence），独立（Independence），互赖（Interdependence）。

效能定义：产出/产能的平衡。为了提高效能，我们必须在提高产出的同时，提高我们的产能。如在高强度压力下提高产出的同时，个人需要注意适当的休息。

人际关系的本质就是情感账户，要记得时常投资，保存账户的余额。

遇到问题，要看反面，因为问题的反面就是契机。
