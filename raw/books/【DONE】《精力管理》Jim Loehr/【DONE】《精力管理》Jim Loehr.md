# 【DONE】《精力管理》Jim Loehr

精力需要全情投入，包括体力、情感、思维、意志四个方面共同作用，缺一不可。并且这四个方面均具有消耗和恢复周期，需要适度使用，注意休息

全书架构：什么是精力-精力的四个方面-如何管理

讲道理，并非管理精力，而是对精力进行投资。投资的含义是可以预见到精力的变化，就现阶段的精力进行投资，在某些关键结点上进行高效投资，为了往后更好的产出。

精力管理要求人做到全情投入，从如下四个维度进行投入评价：体力、情感、思维、意志。最终的输出是乘法运算，即体力x情感x思维x意志。如果其中某一项为0，则总和为0。

体力：身体状态（多吃低升糖食物，保证能量不断输出；勤锻炼身体）

情感：情绪恢复能力（能够快速从悲伤情绪中恢复的能力）

思维：思考专注度

意志：个人价值观（个人宣言）

四个维度的消耗与恢复周期。即体力、情感、思维和意志都是有消耗和恢复周期的，与肌肉一样。不科锻炼过度，也不可完全不锻炼。适当锻炼，突破极限，可不断进步。

“仪式习惯”。仪式习惯固然好，但是如果要养成，是需要大量自律的。同一时间，不可同时进行过多的仪式习惯，否则适得其反。因为人的自控力是有限的。

生活只是实现个人价值观的载体，而不是为了生活而生活
