# 【DONE】《关键对话》Kerry Patterson

通过“陈述事实>自己想法>对方观点”的讲述方法给他人陈述问题，用“赞同>补充>对比”的顺序进行回应，并时刻铭记对话的目的是为了达成共识，不是捍卫自己的立场

什么是关键对话：三个特征：高风险、不同观点、情绪激烈。由于这些对话会对人的生活造成深远的影响，因此称之为“关键对话”

对话的意义在于：信息的自由交流。为了达到这个目的，我们的首要目标就是，营造一个安全环境，使得双方都十分愿意坦诚的交流自己的意见，分享自己的观点库。

把别人的沉默和暴力看成是你们的对话失去安全感的信号，而不是针对个人的鲁莽情绪行为。这种新的思考角度有利于控制自己的情绪，从而冷静的思考来改善对话环境。

行为模式概念：所见所闻->主观臆断->形成感受->展开行为。一般来说，当激烈情绪主导对话的发展时，我们往往会选择性略过“所见所闻”这个阶段，而直接进入“主观臆断”阶段，即不去考虑事实，就观察到对方的行为之后做出的直接反应，毫无疑问，这样对事物的反应态度是缺乏事实基础的，为了避免进入这样的不良循环，改变我们的主观臆断，我们必须学会提升自我意识，即在遇到关键对话时，关注“所见所闻”，注重事实，明确自己的真实目的是什么。

【讲述技巧】综合陈述法可以用于讨论某项关键事宜。具体步骤：

陈述事实->说出自己的想法->征询对方的观点。

学会说：“我说明白了吗？”，而不是“你听懂了没有？”

【回应技巧】在对方表达完自己的想法之后，自己的回应技巧：

赞同->补充->对比。即首先赞同对方的观点，然后继续补充自己的观点，最后把两者的不同对比出来。

【译者】两个原则：明确对话目的（是为了达成共识，而不是捍卫自己的立场）、维护对话安全感

【作者】两个原则：自我意识、营造对话安全感

技巧1：讲事实（无争议）->讲述自己的观点->征询对方的观点（“我想听听你的想法是什么？”）

技巧2：赞同->补充->对比。即：我赞同你的观点，我在做一下补充，最后，我们来对比一下我们观点之间的差异

技巧3：将愤怒看成是失去安全感，而非针对个人的言语攻击

自我意识的重要性：在谈话中间，意识在自己正在失控，然后想起这本书中讲述的安全感两个原则和三个技巧，并且经过反反复复的迭代训练和复盘，关键对话的实力就会逐步提高。
