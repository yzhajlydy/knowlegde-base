# 【DONE】《人性的优点》戴尔·卡耐基

事情本身不会让我们忧虑，是我们对事情的反应让我们忧虑。所以我们要做的是改变自己对事情的态度。三步法：找出最坏结果，接受结果，思考对策避免最坏情况发生

关于忧虑的基本事实

1. 重点不是聚焦模糊的未来，而是着手于清晰的当下
2. 可以尽力为明天做周全的准备，谨慎地思考、规划、准备，但不要忧虑
3. 解决烦恼局面的法则：
4. 找出最坏结果
5. 调整心态接受（Permission to be human，非常重要的一步，也比较困难）
6. 思考对策避免最坏结果
7. 很多生理疾病其实是由于精神疾病引起，比如无用、沮丧、焦虑、担忧、恐惧、挫败、绝望

分析忧虑的基本技巧

1. 解决忧虑的第一步：弄清事实。不要在尚未弄清事实的前提下做任何决定

打破忧虑的习惯

1. 治疗忧虑的方法：让自己全身心投入到工作中，以无暇顾及忧虑
2. 查查数据问问自己：我们担心的事情发生的概率就用有多大
3. 境遇本身并不能决定我们是否快乐，是我们对境遇的反应决定了我们的感受
4. 接受无法避免之事。对我们能力范围以外的事情忧虑完全没有必要
5. 把过去留在过去，不要试图改变过去（不要为打翻的牛奶哭泣）

心态平和的七个方法

1. 我们的心理状态决定了我们的命运
2. 我们要关心遇到的问题，但不要担心
3. 打败你的并不是你的遭遇，而是你对待遭遇的态度
4. 通过主观的调整行为，间接的调整情绪：嘴角微笑或者装作高兴的样子，会带来想不到的效果
5. 你的恨意伤不了对方一根汗毛，却让自己日夜心神不宁，陷入痛苦的深渊；不要浪费一分钟的时间去想那些自己不喜欢的人
6. 原谅并且忘记敌人的有效方法：专心追求更伟大的目标。当你的心思都在专注于目标时，其他任何事情都无法吸引你的注意力
7. 偶然收到致谢，是额外的惊喜；如果无人感激，也是理所当然，不应为此烦心
8. 别人忘记感恩是合乎常理的事情，如果期望得到感谢，那只是自寻烦恼
9. 我们渴望被爱，但世界上唯一一种得到爱的方法，就是不求回报的付出爱
10. 付出帮助是优越的表现，接受帮助是软弱的表现
11. 若想培养知恩图报的子女，我们自己要先懂得感恩

如何避免因批评而焦虑

1. 不公的言论是变相的赞美，因为人红才会是非多
2. 真心实意的欢迎一切真诚有益并且有理论根基的批评

防止疲累和忧虑的六个方式

1. 疲劳会降低身体对普通感冒和上百种其他疾病的抵抗力
2. 短时间的休息蕴含着巨大的修复力，即使短短五分钟的小憩也可能预防疲倦
3. 疲劳大部分源自我们的精神状态和情绪状态，纯生理原因引起的疲劳很少见
4. 精力耗能最大的人的眼睛，占据了四分之一
5. 倾诉能够让患者从焦虑中释放自我
6. 防止疲劳和忧虑的四个工作习惯：
7. 清理书桌，保持整洁
8. 按照轻重缓急处理事务（能力非常重要）
9. 事情已经准备好则立即着手解决，不要拖延
10. 学会组织、委任和监督指导
11. 做自己喜欢的事情，我们很少会感到劳累
12. 为失眠这件事担忧给自己造成的伤害远远大于失眠本身（就算躺到天亮又如何，睡不着起床看书、工作）
13. 解决失眠的其中一个比较好的解药是：让身体感到疲劳，即运动
