# 我们为啥总花钱买没用的东西?异常消费之交易效用

1. 产品总效用=获得效用（f（z-p））+交易效用（f（p *-p）），其中z为价值，p为价格，p*为参考价格
   1. 你认为的产品总效用由获得效用和交易效用组成，你觉得价值高，但是卖的价格低了，你会觉得赚到了，这就是获得效用高
   2. 你觉得价格虽然高，但是参考价格更高，你也会觉得赚到了，这就是交易效用高
   3. 举例：旅游高价购物你不需要的东西、图书定价原价更高、电商划线价、优惠券

# 详细解读锂离子电池微观尺度下的工作原理（收藏必备）

1. Li原子有两层电子壳，第一层2个电子，第二层1个电子，最外层电子非常容易失去，容易形成电流
2. 充放电过程：电场通过场把能量传递到灯泡，正离子在电解液中慢速运动（扩散）；Li原子在电解液的两边一会失去电子，一会捕获电子，不是同一个电子
3. LiNi电池：Ni的氧化物缺电子，向Li原子借电子
4. 充电过程（分离Li原子的粒子和电子）：Li+粒子电离进入电解液进入到负极，电子经过外部回路进入到负极和Li+重新结合成Li原子

   ![](image/image_wBY478loR2.png)
   1. 随着充电的时间增加，正极失去的Li原子越来越多，正极就把电子拽的更紧，需要更高的电压把Li原子分离出来
5. 电解液中有隔膜，目的是通过Li+离子而不通过电子，避免正极和负极材料短路；电解液必须呈现电中性
6. 负极材料的表面因为电解液中有VC溶剂所以会形成一层保护膜（SEI膜），从而保护负极材料，这会消耗5-10%的Li，从而降低5-10%的电池容量【出厂前就已经发生了】

   ![](image/image_ox_GGKcSFP.png)
7. 嵌入：来自导线中的电子与Li+在石墨层中间碰头合并为Li原子，这种现象叫做嵌入

# 俞敏洪整理一次书架要多长时间？10000本书，哪种排序算法最好

1. 直接排序。每次选最小，逐步排最小。复杂度恒定n2
2. 冒泡排序。相邻选最小，逐步排最大。复杂度平均n2
3. 快速排序。选某个标准，小的在前，大的在后。复杂度平均nlog2n，最差n2
4. 归并排序。先分组，再合并。复杂度平均和最差都是nlog2n

# 室温超导硬核解析：未来已来还是科学骗局？

1. 普通金属为什么通电会发热？

   ![](image/image_8HfeRKEB_S.png)

   正电荷固定在栅格里做小范围的运动，自由电子来回运动形成电流，自由电子在运动过程中撞击正电荷栅格从而引起发热
2. 在金属温度降低到一个临界温度时会产生电阻变为0的现象
3. 完全抗磁性：磁场无法穿透超导体，而是绕过超导体，超导体内部产生与外界反向的磁场，实现物体的悬浮
   1. I型超导体：完全无法穿透
   2. II型超导体：一部分磁场可以穿透。现在大部分的超导体实验是II型的，这种超导体可以实现物体的空中悬浮
4. 超导体的应用
   1. 输电导线
   2. 计算机芯片
   3. 强大磁场。核磁共振，拍的更清晰
   4. 磁悬浮
5. 超导体的方法：降温、加压

# 硅谷银行为何倒闭？这和全球疫情、中美摩擦、俄乌战争都有关

1. 为什么会发生通货膨胀
   1. 需求变多了。如需求释放，更有钱
   2. 供给变少了。外部不可控因素，越南水灾导致硬盘价格上涨
   3. 解决通货膨胀的常见方法：加息。增加存款利息和贷款利息，通过这两种方式减少货币流通量，从而降低通货膨胀的影响
      1. 增加存款利息，居民不愿意消费，都把钱存银行了，抑制消费需求
      2. 增加贷款利息，企业不愿意贷款，组织货币流动，抑制供给
2. CPI是消费价格指数，用于判断通货膨胀
   1. 一般2%比较合适
