# 人造与天生

1. 我们开发制造的机器人，大多数是从生命体中得到的灵感：自我复制、自我管理、自我修复、进化和局部学习
2. 基于天然的人造系统，称为“活系统”。例如电话系统、计算机病毒、机器人原型机、虚拟现实、合成的动画角色、人工生态系统

# 蜂群思维

1. 涌现：量变引起的质变
2. 活系统的普遍规律：低层次的存在无法推断出高层级的复杂性
3. 人的大脑类似网路结构，不同的区域控制着不同的功能
4. 大脑对曾经发生过的事情是不会忘记的，只是记不起来而已。它具有精准的回放功能
5. 分布式系统和蜂群思维的独特优势：能够抵抗突然的意外。原因是没有中心，且有足够冗余
6. 温度是大量分子集中涌现的结果：单个分子没有温度可言
7. 分布式系统的四个特点
   1. 没有中心
   2. 区域自治
   3. 区域高度连接
   4. 点对点之间有非线性因果关系
8. 蜂群系统的缺陷
   1. 因为冗余，所以效率低下，浪费资源
   2. 无法集中力量办大事。因为没有中心
   3. 不可预测
   4. 响应很慢。系统复杂，传导路径慢
9. 网络是21世纪的主旋律，纠结是网络的特征

# 有心智的机器

1. 当某个系统能够正常运转时，不要扰乱它，要以他为基层来构建
2. 复杂性依靠的是叠加，而不是推倒重来，它是在基本结构上累积起来的，这样最底层的稳定行为不会被扰乱
3. MIT移动机器人实验室给出来的分布式控制方法论
   1. 先做简单的事
   2. 要准确无误的做简单的事
   3. 在此基础上，增加新的层级和决策
   4. 不要改变简单事物
   5. 让新的层级继续保持准确性
   6. 重复以上步骤，无限类推
4. 自上而下的分解就好比大数质因数分解，很难且不切实际；而从下往上的演化就好比乘法运算，简单而可靠
5. 复杂系统不是设计出来的，而是从简单系统上叠加出来的，是先简单，后复杂
6. 未来机器人的发展趋势：便宜，微小的机器人，而不是大型、庞大的机器人，因为后者过于复杂
7. 未来社会的图景：与人造生物共生，相互依赖；而不是人类和机器只有一种存在

# 组装复杂性

1. 复杂系统对初始条件确实很敏感，但是每一种系统都能达到稳定状态
2. 复杂的机器必定是逐步的，慢慢的完善，别指望通过一次华丽的组装就能完成整个工作正常的机械系统

# 共同进化

1. 场的平方反比规律。存在与物质世界，而在计算机世界则不存在这种规律
2. 共同进化：相互影响的物种间交互的进化演变。共同进化意味着双方需要相互依赖，可能存在一方依赖较多的情况发生，此时就是寄生关系
3. 可以通过观察星球发射的光谱来判断星球是否有生命，原理是但凡有生命的星球，其大气组成会维持在一个高度不稳定的动态平衡
   1. 比如地球的氧气浓度为20%，保持了几亿年。如果没有生命，氧气浓度会快速下降并只剩下二氧化碳
   2. 背后有一只看不见的手在维持地球活泼的大气性质，这就是共同进化的生命
4. 环境塑造了生命，生命通过共同进化的方式反过来影响环境，也就是说环境即生命，生命即环境
   1. 蜥蜴和镜子、植物和昆虫、岩石和生命、人类和机器
5. 在共同进化的过程，演化出一种综合效益最高的策略：一报还一报
