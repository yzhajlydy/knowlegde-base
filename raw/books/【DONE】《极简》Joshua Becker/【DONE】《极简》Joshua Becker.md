# 【DONE】《极简》Joshua Becker

少即是多，只有少，才知道什么对自己是重要的

1. 不要为了缩减而缩减，缩减是为了理清楚对自己来说，真正重要的是什么，不要让那些不重要的事物填满了自己的生活，变得有压力，焦虑，痛苦
2. 产品的极简设计，无论是ipad屏幕设计还是产品线的清晰度。苹果产品的极简只是外表看起来的表现，实际上是因为他们对产品的一种专注，清楚的知道一个产品真正关注的应该是什么，然后把所有的精力全部花在这个上面。比如ipad对屏幕的诠释，所有的硬件服务全部为屏幕做准备。只有关注真正重要的东西，才会舍弃一些不重要的东西。
3. 产品线专注问题。不要让用户来选择我该买什么产品，而是有清晰明确的指南。比如苹果店的展览平台上每台机位有机型比较页面。
4. 极简其实是一种时代的产物。以前物质匮乏，所以需要搜集各种物资，把物品全部屯起来。但是随着时代的发展，信息越来越丰富，我们不会再因为食品匮乏而饿肚子，庞大的物质和信息流进入到我们的大脑里，以至于我们无法处理，也就是信息过载，所以现在需要做信息筛选。这个过程，其实就是由少到多，再从多到少的一个过程。
5. 极简只是手段，目的是为了找寻生活的重点。
