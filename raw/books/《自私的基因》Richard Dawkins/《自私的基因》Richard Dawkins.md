# 为什么会有人呢？

1. 本书的基本观点：进化的关键（或者基本单位）不是物种，而是基因
2. 成功基因的突出特点是其无情的自私性，而在表达自私性的过程中，也会滋长一些有限的利他主义
3. 作者发声：书本只是阐明生物进化有自私的倾向性，并不代表作者本人提倡人类就越自私越好；我们需要严肃对待阐述和支持是两回事
4. 作者发声2：尽管动物的宏观行为上确实可以看出有自私或者利他，但是动物本身或许有可能，也不一定能意识到自己有自私或者利他的意识
5. 类群选择是一种老旧的观点：认为动物个体表现出来的利他行为是在群体层面上的一种选择机制，确保整个物种能够不断繁衍和传播下去
6. 为什么类群选择观点具有强大的生命力？因为这和人类的价值观一致：把一个行为从生物层面拔高到不存在的精神层面，放大了道德层面（利他）
7. 待验证观点：基因是否就是最底层的选择单元，是否有可能再往上一个层面：比如胚胎

# 复制因子

1. 达尔文的“适者生存”，其实是“稳定者生存”的特殊情况。什么是稳定的？
   1. 能够复制自己的
   2. 复制的速度快的
   3. 复制的准确度高的
2. 自然选择其实是有方向的，这个方向就是稳定的，淘汰不稳定的；不一定是复杂的，不一定是最大的，但是一定要能够复制自己的，这就是复制因子
3. 在狭小的环境中模拟地球还没有生命时期的环境（CHON），制造各种闪电，最后衍生出氨基酸物质
4. 生物进化需要错误，错误带来不一样，不一样就有可能出现对的方向，这需要庞大的基因数量

# 不朽的双螺旋

1. DNA做的最重要的两件事：
   1. 自我复制
   2. 指导RNA合成蛋白质
2. 任何一个基因起作用都离不开其他基因和他一起，是综合作用出来的结果
3. 基因就是有头，有尾的核苷酸ATCG的序列
4. 遗传单位越短，生存的时间就越长。原因是出错的概率越低
5. 个体之间的基因可以相互融合和交换，但是基因不会。基因是最小的遗传单位，他必须保持一致性，否则基因就无法稳定的遗传下去
6. 基因可以永垂不朽，而个体，种群都是基因不断延续下去的手段而已
7. 不用纠结为什么个体会消亡，要关注的是个体、种群的消亡对基因频率这个维度上有什么贡献和损失，这才是基因真正关心的指标和最终目的

# 基因机器

1. 基因无法预测未来，但是制造了一种负反馈机制：好的东西继续保持，不好的东西远离。比如甜食、性，痛苦和饥饿要远离

# 进犯行为：稳定性和自私的机器

1. 进化稳定策略的实质是：在一个群体里，如果你想保证自己的基因可以长久留存下去，那么你必须做大多数人所做的事，就是说做大多数人所做的事是一种稳定的策略
