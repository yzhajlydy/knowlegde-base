# 【DONE】《史蒂夫 乔布斯传》Walter Isaacson

1. 小时候的乔布斯家住在硅谷，身边都是高科技的公司、企业和人才，耳濡目染，有利于他的后天成长
2. Intel的简称由来集成电路公司（Integrated Electronics Corporation），简称Intel
3. 高中时代的乔布斯遇到了一个天才硬件工程师：沃兹尼亚克，他们俩玩的挺好，是苹果计算机公司的创始人之一。凭借乔布斯的市场销售天赋和沃兹出色的技术，在高中阶段制造出一个蓝盒子，用途就是用特定的频率欺骗电话系统，打国际免费电话。
4. 1970年代的美国大学，寝室的卧谈会基本上是围绕“自我实现”的兴趣话题。
5. 乔布斯是一个禅宗信徒，信奉极简主义的美学观点和执着的个性
6. 素食主义、佛教禅宗、冥想、迷幻药、摇滚乐
7. 乔布斯在2005年的斯坦福大学毕业演讲中提到：在里德学院学到的衬线字体和无衬线字体最终应用到了苹果计算机的字体中
8. 乔布斯曾去过印度呆了7个月，他十分欣赏那边的禅宗思想，认为：直觉是非常强大的，他比思维更加强大。理性思维是可以通过后天学习培养出来的，而直觉不行。
9. 苹果公司的“苹果”由来：因为在提交名字的前一天，乔布斯刚刚从苹果农场回来，并且“苹果”这个词削弱了“电脑”这个词的锐气，更接地气。并且这也能让公司在黄页上更靠前。
10. 苹果笔记本电脑里面都是没有风扇的，因为乔布斯认为计算机内部的风扇有悖于禅意，它们的噪音会让人无法集中精神。
11. 好的艺术家抄袭创意，伟大的艺术家窃取灵感
12. 桌面的概念也是乔布斯提出：比如图标的设计、位于窗口顶端的下拉菜单设计、双击鼠标打开文件和文件夹的功能
13. 1970年代，当时的计算机显示基本上都是字符显示，有一家施乐PARC公司拥有位图的图形界面显示技术，但是并没有很好的普及。乔布斯发现后立马将其应用在苹果电脑上。
14. 乔布斯著名的二元分类体系：非黑即白。一个人不是天才就是蠢货，一个产品，不是绝妙至极就是垃圾透顶。
15. 注意苹果所有界面的圆角矩形的界面设计
16. 苹果产品中的计算机是乔布斯自己做的
17. 苹果公司每半年会有一次集思会
18. 斯卡利原来是百事可乐的总裁，后来乔布斯看重了他的才能准备把他挖过来，在他们谈判的过程中，乔布斯说出了那句经典的话“你是想卖一辈子糖水呢，还是想抓住机会来改变世界？”
19. Mac团队的一个特点是产品在发布之前，一直处于研发状态
20. 盖茨懂计算机编程，务实，有原则，且拥有很强的分析处理能力；乔布斯更相信直觉，更浪漫，而且在技术实用化、设计愉悦感和界面友好方面有着更高的天分。
21. 微软的桌面系统实际上有抄袭苹果公司桌面概念的嫌疑
22. 乔布斯收购了乔治卢卡斯的动画部门，成立皮克斯动画工作室，创作出了诸如《玩具总动员》、《海底总动员》、《机器人总动员》、《虫虫危机》等伟大的作品。是一间融合了科技和艺术的工作室。
23. 微软的第一批应用软件其实是为Mac开发的Excel和Word
24. 可以看到苹果店的付款流程也被简化，由甲骨文公司开发的手持结账系统软件大大简化了付款流程。
25. 苹果专卖店的标志：立方体、标志性楼梯、玻璃
26. 数字中枢的概念非常重要：它的本质是将我们对创意艺术的欣赏（音乐、视频）和伟大的工程技术结合起来。数字中枢整合各种数字设备，包括音乐播放器、录像机、相机等。即计算机+设备+软件的整合。
27. 苹果是唯一一家提供整合方案的公司：硬件、软件、数字设备、应用程序、音乐、视频、图片等
28. ITunes商店使得人们可以购买音乐，让人们可以“拥有”音乐
29. ipad的想法实际上先于iphone出现，准备在ipad上实现的多点触控功能被首先应用于iphone上
30. 安卓的触摸屏界面其实都是来自苹果的首创功能：多点触控、滑动操作、应用程序图标网格、双触点滑动缩放、手持姿态传感器等
31. 实际上云端的概念早有提出，比如微软、亚马逊和谷歌在2011年就退出了云服务，但是他们并没有整合硬件、软件和设备中的内容，但是苹果因为控制了整个环节，所以一马当先提出了iCould用于同步音乐、视频、备忘录等功能。
32. 苹果和谷歌、微软走两种路：前者是一体化系统，走封闭路线，优势是用户有更多的选择自由；后者开放系统，走开放路线，优势是界面更简单，电池寿命更长，更易操作

34. 乔布斯将自己置身于“艺术”与“科技”的交汇处，在他所有的产品中，科技必定与完美的设计、外观、精致、手感、人性化甚至是浪漫结合在一起
35. 你永远不该怀着赚钱的目的去创办一家公司，你的目标应该是做出让自己深信不疑的产品，创办一家生命力很强的公司。
36. 苹果营销哲学：
37. 共鸣：紧密结合顾客的感受，即理解使用者的需求
38. 专注：丢弃掉不重要的事情，专注做最重要的事
39. 灌输：通过产品设计、外观、质量向用户传达我们的理念（包括产品展区的选择和装潢）
40. 乔布斯设计理念的决定性原则：“至繁归于至简”
41. 乔布斯的现实扭转力，认为只要有激情和想法，就可以改变现实，做出惊人的举动。
42. 产品要做到极致的简约，要让产品达到在现代艺术博物馆展出的品质。值得注意的是简约化设计应与产品的简单易用性结合起来，设计上的简单并不总能带来操作上的简易。简洁并不仅仅只是视觉上的，也不仅仅是把杂乱无章的东西变少或抹掉，而是要挖掘复杂性的深度，要想获得简洁，必须要挖的足够深，了解内在复杂的原因，深刻把握产品的精髓，从而判断出哪些不需要的部件是可以拿走的。即：设计不仅是关于产品的外观，而且必须反映出产品的精髓。
43. 伟大的艺术品不必追随潮流，因为它自己就可以引领潮流。好比法拉利、保时捷本身都代表了使用者的身份，那么苹果公司的产品也要做到这种层次，他创造了科技行业唯一一个时尚生活品牌
44. 乔布斯认为一台电脑要真正做到优秀，其硬件到软件必须要紧密相连
45. 客户并不知道自己要什么，直到你把产品摆在他面前
46. 一流的队员只喜欢同一流队员合作，这就意味着团队不允许出现二流队员
47. 在人生的头30年里，你培养习惯，在后30年，习惯塑造你
48. 一家伟大的公司给人的第一印象就必须映射出自己的价值观
49. 乔布斯拥有惊人的专注力，对其他事情完全没有反应。
50. 长盛不衰的公司都知道如何重塑自我，也就是创新，唯有创新才是公司的唯一出路
51. 公司产品线不宜过多，成功的产品应该让消费者清晰地知道自己应该买哪款产品
52. 必须在商店里就把我们的理念传达给顾客
53. 一家好的公司要学会“灌输”：它必须竭尽所能传递它的价值和重要性，从包装到营销
54. 公司应该是一个整体，不应该被分割成太多自主部分。作为一个整体就可以紧密的控制所有团队，作为一个团结而灵活的整体一起工作。
55. 公司会在每周举行管理团队会议，讨论的重点常常着眼于未来：每款产品接下来怎么做，应该开发哪些新东西？利用这种会议加强公司的共同使命意识。
56. iphone的重点是屏幕显示，所以所有的设计都应该为这个产品的重心服务，所以屏幕采用了玻璃材质，边缘也被设计的不显眼。同样，ipad的设计重心也是屏幕，因此所有的功能和设计都必须服从屏幕的需要
57. ipad的设计有一个故事：有一位客户在某个农村的奶牛场用ipad看小说，一个扫马厩的6岁小男孩走了过来，于是他把ipad递给了这个小男孩，小男孩在没有见过电脑的情况下，凭自己的直觉使用ipad，在屏幕上滑动，启动应用程序，玩弹珠游戏。充分说明了ipad设计的简洁性和对复杂功能的解刨能力
58. 每一个产品都应该有自己的灵魂和使命，他们被制造出来，就代表了一项功能，可以用一句话来表示他们的作用。如ipod——把1000首歌装进你的口袋，ipad——应用程序商店
